# OHT Animation

An Overhead Hoist Transport (OHT) animation for **NVIDIA Isaac Sim 6.0**. The OHT picks a magazine up from **Machine 1**, drives around the rail loop, and places it on **Machine 2**.

> **Status:** Work in progress. 

## What it does

1. Drive to Machine 1
2. Lower the hoist, close the claws, lift the magazine
3. Drive along the rail loop
4. Lower the hoist, release the magazine on Machine 2, lift the hoist
